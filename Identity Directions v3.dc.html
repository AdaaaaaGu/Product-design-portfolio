3Diagram standard — the grey system every figure uses
3aTokens — one surface, one fill, one ink, one accent. Every diagram, placeholder, and figure plate in the portfolio sits on these. Lightened from the first pass so a figure reads as a panel on the page, not a hole in it.

Rules

Accent marks meaning, never decoration — a junction, a counted item, the one thing being argued.

Two greys only inside a diagram: surface and fill. Depth comes from outline weight, not more greys.

Outlines are non-scaling, so line weight stays constant while a diagram zooms.

Type in figures

Instrument Sans throughout. Structural labels 600 weight, uppercase, tracked; measurements and asides 400–500 in muted.

Nothing below 12px rendered, at any zoom level — check it at the figure's real width, not the artboard's.

In-figure labels use #6E7076, a step darker than page muted, to hold contrast against the figure surface.

3bApplied — the Halliburton P&ID figure built on 3a. Four beats, autoplaying once on scroll. This is the reference for how a diagram should look and behave.
2Airier riffs on 1a + 1d
2aColumn — 1a's centering with 1d's type covers. One project per full-width row, hairlines instead of cards, enormous vertical air. Nothing but type, rules, and one grey plate per project.
